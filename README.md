# 📊 Customer Segmentation & Marketing Campaign Analysis

## 📌 Project Overview

This project is a Power BI dashboard developed to analyze customer demographics, purchasing behavior, income levels, and marketing campaign responses.

The dashboard provides interactive visualizations that help understand customer characteristics and identify useful patterns for customer segmentation and targeted marketing.

## 🎯 Project Objective

The main objectives of this project are:

* Analyze customer demographics
* Understand customer purchasing behavior
* Identify spending patterns
* Analyze customer preferences
* Visualize customer characteristics
* Support targeted marketing decisions

## 🛠️ Tools & Technologies

* Power BI Desktop
* Power Query
* Microsoft Excel / CSV
* Data Visualization
* Customer Analytics

## 📂 Dataset

The project uses a Marketing Campaign / Customer Personality Analysis dataset containing customer demographic, income, purchasing, and campaign-related information.

### Important Features

* Customer ID
* Year of Birth
* Education
* Marital Status
* Income
* Recency
* Product spending
* Web purchases
* Catalog purchases
* Store purchases
* Deal purchases
* Campaign responses

## 🧹 Data Cleaning

The dataset was cleaned using Power Query before creating the dashboard.

The following preprocessing steps were performed:

* Checked for missing values
* Removed null values
* Checked data types
* Checked for duplicate records
* Verified numeric and categorical fields
* Prepared the dataset for visualization

## 📊 Dashboard 1: Customer Overview

The first dashboard provides an overview of the customer base.

### Key Performance Indicators

* Total Customers
* Average Income
* Average Recency
* Total Complaints

### Visualizations

* Customers by Education
* Customers by Marital Status
* Customer Distribution by Birth Year
* Income Distribution

### Interactive Filters

The dashboard includes filters for:

* Education
* Marital Status
* Income
* Year of Birth

## 💡 Key Insights
